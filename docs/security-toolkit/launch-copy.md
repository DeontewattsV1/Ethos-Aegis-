# Ethos Aegis — launch copy

Five security tools. One immune architecture. Evidence before action.

Find credential exposure with TruffleHog.
Review your username exposure with Sherlock.
Inspect compiled artifacts with Ghidra.
Audit your application's egress with mitmproxy.
Review your wireless lab inventory with ESP32 Marauder.

Ethos Aegis wraps these workflows with scoped targets, private reports, source fingerprints and a review path. Execution defaults off. Observations stay distinct from verified findings.

The AI side brings Sentinel cells, signature memory, vitality telemetry, provider adapters and VeriFlow reasoning into the same repository.

Three local walkthroughs. Synthetic inputs. Actual code.
Open the README, watch a demo, then try an authorized local workflow.
