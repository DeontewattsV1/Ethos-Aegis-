# AEGIS Private Shield v0.2 — Acceptance Boundary

This increment is accepted only when the same focused Private Shield suite passes on Linux, macOS, and Windows and the non-Linux jobs publish inspectable JUnit artifacts.

The executable boundary covered by this increment is:

```text
canonical path namespace
  -> default-deny authorization
  -> opaque secret lease
  -> mediated MCP invocation
  -> trusted adapter secret use
  -> tamper-evident receipts
```

Required containment properties:

- host-specific path aliases and traversal fail closed;
- raw secret material is not present in agent-visible leases;
- a consumed one-use lease cannot be replayed;
- direct secret reflection by a trusted adapter is blocked;
- denied MCP requests do not execute handlers;
- MCP execution requires the intersection of caller, tool, project, environment, risk, and flow authority;
- an MCP adapter can consume an opaque lease without exposing the underlying credential to the caller;
- authorization and execution evidence remain hash-linked.

Production secret stores and real MCP transports remain outside this reference increment and must preserve these same boundaries when introduced.
